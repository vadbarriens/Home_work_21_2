# Домашнее задание - Веб-приложение с Bootstrap

## Описание проекта

### Простое веб-приложение, которое возвращает HTML-страницы с использованием Bootstrap. Реализовано:

- Верстка 4 страниц по макетам
- Базовый HTTP-сервер на Python
- Обработка GET и POST запросов
- 
## Структура проекта

```
Home_work_21_2/ 
├── src 
   └── app.py # Основной файл приложения
├── .gitignore
├── catalog.html # Страница каталога
├── category_1.html # Страница категории
├── contacts.html # Страница контактов
├── home.html # Главная страница 
├── README.md 
└── requirements.txt
```

## Установка и запуск
1. Клонировать репозиторий:

git clone https://github.com/vadbarriens/Home_work_21_2
